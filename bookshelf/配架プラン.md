# 本棚 配架プラン

作成日: 2026-08-27 ／ 対象: 蔵書リスト（`蔵書リスト.md`）の68点

## 現状の課題

1. **同じテーマが棚をまたいで分散している**
   - 一般社団・財団法人: 棚A（A-11）と棚C（C-06〜C-11, C-17）に分散
   - Web3・DAO: 棚C（C-12〜C-16）と棚D（D-04 DAOの実務）に分散
2. **雑誌（月報司法書士・金融法務事情）が単行本の間に混在**している
3. **旧版と新版が並んで現役棚を占有**（合同会社の運営と理論 第2版／第3版）
4. **裏向きの本**（C-17）があり背表紙で探せない
5. 一筆箋などの**文具が本の前に立てかけてあり**、後ろの本が見えない

## 配架の5原則

1. **テーマの島を作る** — 1テーマ1箇所。探すときに1つの棚だけ見ればよい状態にする
2. **会社のライフサイクル順に並べる** — 設立 → 株式・組織再編 → 承継 → 清算、と流れで置くと案件の局面から本を引ける
3. **使用頻度の高い実務書を目線の高さに** — 商業登記・組織再編・合同会社のコア実務書を最優先
4. **旧版・雑誌は現役棚から外す** — 旧版は最下段か保管箱へ、雑誌はファイルボックスに集約
5. **シリーズ・著者でまとめる** — 金子登志雄／立花宏の組織再編・商業登記シリーズ、幸良秋夫の設問解説シリーズなどは隣接させる

## 運用ルール（提案）

- **新刊の定位置**: 買ったらまず分類を決めて島に差す。「とりあえず空いている所」に置かない
- **旧版**: 新版を買ったら旧版はその場で最下段・保管箱へ（比較参照が必要な間だけ隣に置く）
- **雑誌**: ボックス1つを「未読・参照中」、もう1つを「保管」にする。年1回、保管分を整理
- **棚ラベル**: 各島に「株式・組織再編」「一般法人」などのラベルを貼ると、戻す場所に迷わない
- **台帳**: `蔵書リスト.csv` に購入日・貸出メモの列を足せば簡易蔵書管理台帳になる
