## クロージング当日に「辞任＋就任」を成立させる

株式譲渡によるM&Aでは、譲渡代金の決済日（クロージング日）に、旧オーナー側の役員が辞任し、買主側の役員が就任するのが典型です。登記としては次の変更を同時に申請します。

- 取締役・監査役の辞任と就任（会社法915条1項、2週間以内）
- 代表取締役の変更（住所を含む）
- 会社届出印の改印（印鑑届書の再提出）
- 併せて商号・本店・目的・事業年度の変更や、監査役設置の廃止などを行うことも多い

クロージングは「株式譲渡の効力発生」と「役員の交代」が同じ日に起きるため、**株主総会をどの株主が開くのか**、**辞任日と就任日の前後関係をどう組むか**を事前に決めておかないと、登記の段階で矛盾が生じます。

## 留意点1：取締役会設置会社の員数と権利義務取締役

取締役会設置会社では取締役3名以上が必要です（会社法331条5項）。旧経営陣が3名すべて辞任し、新経営陣の就任が翌日以降にずれると、辞任した取締役は後任が就任するまで**取締役としての権利義務を有する**ことになります（会社法346条1項）。

登記実務上、権利義務を有する状態の取締役については辞任のみの登記はできず、後任者の就任と同時に申請する必要があります。辞任日と就任日が異なる場合でも、登記上は「辞任日」として記録されるのは辞任届の日付ではなく後任者の就任日になる点に注意してください。

員数の問題を避けるには、次のどちらかで組み立てます。

1. クロージング日に開催する株主総会で新任取締役を選任し、同日付で旧取締役が辞任する（辞任と就任が同日）。
2. クロージング前に、旧株主の株主総会で新任取締役を「クロージング日を就任日として」選任し、就任承諾もその日付で取得する。

監査役設置会社の監査役も同様で、辞任により監査役が不在になると権利義務監査役になります。監査役設置会社の定めを廃止するのであれば、定款変更（特別決議）と同時に処理するとすっきりします。

## 留意点2：定時株主総会の基準日と譲渡日のズレ

見落とされやすいのが**議決権の基準日**です。多くの会社は定款で「毎事業年度末日の最終の株主名簿に記載された株主が定時株主総会で議決権を行使できる」と定めています（会社法124条）。

3月決算の会社で、4月に株式譲渡が完了し、6月に定時株主総会を開く場合を考えます。基準日（3月31日）時点の株主は旧オーナーですから、**6月の定時株主総会で議決権を行使できるのは原則として旧オーナー**であり、新オーナーではありません。新オーナーだけで定時総会を開いて役員を選任すると、決議の効力に疑義が生じます。

対応としては次の方法があります。

- **会社法124条4項の活用**：基準日後に株式を取得した者の全部または一部を議決権を行使できる者と定める（取締役会設置会社では取締役会決議）。旧株主が全株式を譲渡している場合、基準日株主の権利を害することにならないため、この方法が使いやすい。
- **旧株主の協力**：譲渡契約で、クロージング後の定時総会に旧株主が協力する（または議決権行使を委任する）旨を定めておく。
- **臨時株主総会での処理**：役員選任は基準日を設けない臨時株主総会で新株主が行い、計算書類の承認など定時総会でしか扱えない事項だけ上記の方法で処理する。

登記の添付書面である**株主リスト**（商業登記規則61条2項・3項）は、総会で議決権を行使できる株主を基準に作成します。株式譲渡の前後どちらの株主構成で総会を開いたのかと、株主リストの記載を必ず一致させてください。

:::warn
書面決議（会社法319条）で処理する場合も、「議決権を行使できる株主全員」の同意が必要です。基準日が設定されているときは基準日株主が同意権者になるため、新株主のみの同意書では足りません。
:::

## 留意点3：辞任届に押す印鑑

代表取締役（代表取締役を置かない会社では取締役）の辞任届には、**会社の届出印（会社実印）または個人の実印**を押印し、個人実印の場合は印鑑証明書を添付する必要があります（商業登記規則61条8項）。

M&Aのクロージングでは、旧代表取締役が会社実印を買主に引き渡した後に辞任届を作成しようとして、会社実印も個人実印も手元にない、という場面が起こりがちです。辞任届はクロージング前に準備し、押印の種類を確認しておくのが安全です。

新代表取締役の就任については、取締役会設置会社では就任承諾書に個人実印を押し印鑑証明書を添付します（商業登記規則61条5項）。取締役会議事録に出席した取締役・監査役が押す印鑑と印鑑証明書の要否は、旧代表取締役が会社届出印を押印しているかどうかで変わります（同条6項）。旧代表取締役が取締役会に出席せず届出印も押さないケースでは、出席者全員の個人実印と印鑑証明書が必要になるので、議事録の押印計画をあらかじめ立てておきます。

## 留意点4：譲渡承認決議と特別利害関係

譲渡制限株式の譲渡には承認機関（取締役会または株主総会）の承認が必要です（会社法139条）。取締役会で承認する場合、**譲渡人である取締役は特別利害関係人**として議決に加われないと解されています（会社法369条2項）。オーナー兼取締役が譲渡人となる典型的なM&Aでは、承認決議の定足数と議決権者の構成を確認しておく必要があります。

譲渡承認自体は登記事項ではありませんが、承認の日付は株式譲渡の効力発生日に影響し、株主名簿の名義書換の日付とも連動します。

## 留意点5：新任役員の任期

定款に「補欠または増員として選任された取締役の任期は、前任者または他の在任取締役の残任期間とする」という規定がある場合、M&A後に就任した役員の任期が想定より短くなることがあります。役員全員が入れ替わるケースでは補欠規定の適用は通常ありませんが、一部の役員が留任する場合は要注意です。

任期満了を見落とすと、次の役員変更登記を失念して過料の対象になり得ます。就任と同時に定款の任期規定を確認し、必要なら定款変更（任期の統一）も同時に行うことを勧めています。

## クロージング前チェックリスト

| 区分 | 確認事項 |
| --- | --- |
| 機関設計 | 取締役会設置会社なら辞任後も3名以上を維持できる組み方か |
| 基準日 | 定時総会で議決権を行使する株主は誰か。124条4項の決定は必要か |
| 株主リスト | 総会時点の議決権構成と一致しているか |
| 辞任届 | 会社実印か個人実印か。印鑑証明書は手配済みか |
| 就任承諾書 | 個人実印・印鑑証明書（発行後3か月以内）の準備 |
| 議事録 | 誰がどの印鑑を押すか。旧代表の届出印押印の有無 |
| 譲渡承認 | 特別利害関係人を除いた定足数で決議できるか |
| 任期 | 補欠・増員規定で任期が短くならないか |
| 印鑑届 | 新代表取締役の印鑑届書と個人印鑑証明書 |

役員変更登記そのものは定型的ですが、M&Aでは「誰がいつ株主で、誰がいつ役員か」の時系列が複雑になります。クロージングの日程を組む段階で司法書士が関与し、決議の主体と日付を一本の時系列に整理しておくのが、登記でつまずかない最善策です。
